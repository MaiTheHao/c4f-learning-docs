# Programming Frameworks

Chuyên mục này tổng hợp kiến thức về các framework lập trình phổ biến, bắt đầu từ hệ sinh thái Spring. Nội dung được tổ chức theo từng framework và từng cơ chế cốt lõi, giúp người đọc hiểu bản chất vấn đề mà framework giải quyết trước khi đi vào cú pháp hay cấu hình chi tiết.

## Spring

Tài liệu Spring trình bày hai cơ chế nền tảng: Aspect-Oriented Programming để mô-đun hóa các concern xuyên suốt, và Spring Expression Language để đánh giá biểu thức động trong cấu hình cùng các tính năng của framework. [Xem Spring Framework](./spring/README.md).

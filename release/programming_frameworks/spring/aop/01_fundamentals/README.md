# Fundamentals

Phần này giới thiệu động cơ hình thành AOP và vị trí của AOP trong thiết kế phần mềm. Nội dung đi từ vấn đề mô-đun hóa đến mục tiêu thiết kế và Trade-off.

## Nội dung

Tài liệu tổng quan giải thích định nghĩa, bối cảnh, quan hệ của AOP với OOP, các khái niệm cốt lõi cùng Trade-off khi áp dụng. [Xem Tổng quan AOP](./aop_overview.md).

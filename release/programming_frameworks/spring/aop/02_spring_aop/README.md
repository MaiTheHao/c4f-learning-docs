# Spring AOP

Phần này chuyển từ khái niệm AOP tổng quát sang cách Spring hiện thực hóa cơ chế đó thông qua proxy và các lời gọi phương thức của Spring bean.

## Nội dung

Tài liệu mô hình giải thích vai trò của Aspect, Pointcut, Advice và các thành phần liên quan, cùng năm loại Advice chính. [Xem Mô hình Aspect trong Spring AOP](./aspect_model.md).

Tài liệu tiếp theo trình bày các giới hạn thực tế của proxy, điều kiện để advice được thực thi và khi nào nên cân nhắc AspectJ. [Xem Proxy và các giới hạn của Spring AOP](./proxy_constraints.md).

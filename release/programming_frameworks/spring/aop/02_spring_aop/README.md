# Spring AOP

Phần này chuyển từ khái niệm AOP tổng quát sang cách Spring hiện thực hóa cơ chế đó ở mức mô hình: aspect, pointcut, advice và proxy.

## Nội dung

Tài liệu mô hình giải thích vai trò của Aspect, Pointcut, Advice và các thành phần liên quan, năm loại Advice chính, và cách đọc pointcut expression. [Xem Mô hình Aspect trong Spring AOP](./aspect_model.md).

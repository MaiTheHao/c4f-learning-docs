# Spring Expression Language (SpEL)

Spring Expression Language (SpEL) là ngôn ngữ biểu thức của Spring Framework, cho phép truy vấn và thao tác trên object tại Runtime. Tài liệu này trình bày bối cảnh ra đời, vấn đề SpEL giải quyết, cơ chế hoạt động, các khả năng chính và vai trò của SpEL trong hệ sinh thái Spring, giúp người đọc hiểu bản chất và phạm vi sử dụng trước khi đi sâu vào cú pháp hoặc các chi tiết triển khai.

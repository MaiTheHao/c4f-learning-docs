# Interesting Docs - Tài liệu Thú vị & Mở rộng Góc nhìn

Phân nhánh `/interesting` lưu trữ các tài liệu thú vị mở rộng góc nhìn, vượt ra ngoài kiến thức kỹ thuật cần-thiết-trực-tiếp: những câu chuyện, nghịch lý và ý tưởng kỳ lạ khơi gợi sự tò mò và tư duy khác biệt.

Triết lý ba tầng tri thức của kho tài liệu này:

- Release Docs (*Need-to-know*: điều cần biết, đã qua rà soát).
- Temporary Docs (*Exploring*: điều đang khám phá, chưa qua kiểm chứng).
- Interesting Docs (*Don't-know-you-want-to-know*: điều bạn chưa biết là mình muốn biết).

4. **Engineering Curiosities** (Những điều tò mò, kỳ quặc trong thế giới kỹ thuật).
5. **Unconventional Perspectives** (Góc nhìn phi truyền thống, lối tư duy khác biệt).
